WHY (Semantic Layer)
  Intent: Connect the full governance loop — Pi Script detects, Rift authors,
  Continuum connects. The human completes. Automation supports oversight,
  never replaces it.
  Governing principle: Clear, context-rich data for decision-making.

WHAT (Constraint Set — Active)
  - Human-in-the-loop philosophy governs all agent autonomy boundaries
  - Violation review workflow must be visible and enforced at the workspace level
  - System boundary definitions must be explicit — no silent overrides
  - Triage tier architecture: defined before Continuum architecture is finalized
    (this is a Continuum decision, not a Pi Script one)

BOUNDARIES (Agent Goals)
  - Design the triage tier and EMERGENCY_OVERRIDE construct before architecture lock
  - Define where automation ends and human review begins for each violation type
  - Do not finalize Continuum architecture until Q1 and Q5 are resolved

PRECEDENCE (@priority: critical)
  - No agent may cross a declared human review boundary silently
  - EMERGENCY_OVERRIDE requires a flagged, non-dismissable RESOLUTION TRACE
  - Reviewer fatigue is a known risk — flat review queue is a bottleneck.
    Severity triage must be in place before volume increases.
